# curve_structure v08 — 復帰基準版（2026-11-19）

## 状態
**v08 を採用する復帰基準版として凍結。v09以降のすべての試行はユーザー判断で不採用。**

これは「完成した高品質のドット絵生成器」ではありません。**原画から描画線の候補と塗り用閉領域を別々に取得する、Pythonによる検証用エンジン**です。線画をきれいにすること・48×64pxへ忠実にデフォルメすることは未完成。

- `curve_structure_v08.py`：表示線画、非表示の閉領域、領域ID、原画色を利用した塗り分けを出力
- `curve_structure_v07.py`：v08が直接 import する領域分割と塗りつぶし用の自作モジュール

依存：Python、Pillow、NumPy、OpenCV。外部AIモデル・研究者個人のコードの流用なし。インターネット不要。

## 起動方法

この2つのPythonファイルを**同じディレクトリ**に置く。

```sh
pip install pillow numpy opencv-python
python curve_structure_v08.py input.png --out v08_output --width 560 --colors 18
```

剣には `--colors 14`、エルフには `--colors 18` を使用した検証履歴がある。これらは対象別のテスト設定であり、エンジン内に特定キャラの手描き座標は埋め込まれていない。

生成される主なファイル：
- `01_visible_lineart.png`：**見える線画。未閉鎖箇所があり、単独でペイントアプリのバケツ塗りを保証しない**
- `01_visible_lineart_alpha.png`：透過の表示線
- `02_hidden_closed_wall_preview.png`：塗り用の閉境界
- `03_region_ids_lossless.png`：機械可読の領域ID
- `04_flat_fill_no_walls.png`：領域を塗り分けた試作
- `05_visible_lines_and_fill.png`：表示線＋ベタ塗りの試作
- `report.json`：処理結果と8方向色漏れ検査
- `06_iphone_review.jpg`：比較用画像
