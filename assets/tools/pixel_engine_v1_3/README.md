# 汎用ドット絵エンジン v1.3

**目的:** 全身正面の原画から、精密マスターとゲーム用透過PNGを同じ処理で量産する。

## v1.2 → v1.3

- 精密マスター（最長辺128px）はv1.2と同条件で生成。旧版64px出力も比較用に再現。
- ゲーム用を最近傍法だけでなく、**透過率つき面積縮小**で再構成。
- 小さくなって消えがちな暗色線を、**原画から得た局所明暗差**で判定し保持。
- 色を隣接ピクセルと合わせる共通の減色処理。顔位置やキャラ種別の決め打ちはなし。
- **64px高（標準）と80px高（視認性優先）**を両方出力。横幅は原画の比率に応じて自動決定。
- PNGの透過は0または255。ドット拡大は最近傍法。

## Pythonでの使い方

`pip install -r requirements.txt`

`python engine.py source1.png source2.png --config config.json --output output`

複数を試す場合も**同じ engine.py と config.json**を利用。`--labels "キャラ1" "キャラ2"` は比較画面の表示名のみ変えます（処理には影響しません）。

### 出力

- `master.png`: 精密マスター
- `before64.png`: v1.2の旧ゲーム版（比較用）
- `game64.png`: v1.3の64px高版
- `game80.png`: v1.3の80px高版
- `comparison.png`: 4種類の比較画像
- `report.json`, `batch_report.json`: 寸法・色数・ハッシュ等

## 限界（重要）

- **ゲーム用の完成品ではなく品質向上の試作**。静止した正面立ち絵です。歩行・攻撃アニメは未実装。
- 頭身の再構成、顔・装飾の意味的な認識、キャラごとの構図調整は未実装。
- 全身・正面かどうかの正確な自動判定は未実装。入力原画の制作段階で確認してください。
- 64pxに収まらない顔のディテールは再現できません。ゲーム側のタイルサイズとの兼ね合いも必要です。
- 白・単色背景または透過原画が得意。複雑な背景は事前除去が必要な場合があります。

## 汎用性

今回の4種類（エルフ、小動物、猫耳獣人、ドワーフ）で共通設定を使用。画像専用座標は本体にありません。
`engine_v12.py` は既存の背景除去・マスター生成を使うための同梱ファイルです。
